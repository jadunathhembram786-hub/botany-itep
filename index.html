Study Guide

A practical way to prepare.

🌱 1. Build concepts

Read the detailed unit notes first. Focus on definitions, mechanisms, pathways and cause-and-effect relationships.

✏️ 2. Practice diagrams

Practice water potential relationships, stomata, photosystems, Z-scheme, C3/C4 pathways, TCA cycle and phytochrome responses.

🎯 3. Attack questions

Use the important-question bank after each unit. Try answering from memory before revealing the answer focus.

🧠 4. Revise actively

Mark topics complete, take the quiz repeatedly and revisit anything you miss.

Exam tip: For long answers, use a definition → mechanism/pathway → labelled diagram or flowchart → significance → conclusion structure.
